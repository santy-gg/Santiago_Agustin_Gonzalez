### Proyectos Destacados

#### AINABI - Plataforma Integral ERP/CRM orientada a RRHH
Sistema de gestión empresarial diseñado para optimizar procesos de recursos humanos combinando una arquitectura backend robusta con inteligencia artificial.

**Arquitectura y Tecnologías:**
* **API REST:** Desarrollada íntegramente en Python utilizando el framework Flask para gestionar la capa de servicios.
* **Base de Datos:** Modelado relacional y gestión de transacciones utilizando PostgreSQL.
* **Inteligencia Artificial:** Implementación de modelos predictivos (Machine Learning) integrados directamente en el flujo de trabajo para analizar y predecir el rendimiento de los empleados.
* **Aseguramiento de Calidad (QA):** Definición, ejecución y gestión de casos de prueba manuales en un entorno ágil (Scrum) para garantizar la estabilidad de las entregas.
